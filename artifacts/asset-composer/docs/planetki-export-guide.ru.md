# Перенос Asset Composer → Planetki

## Персонажи и предметы

Откройте чиби, нажмите **Экспортировать → Экспортировать для Godot / Planetki**. Распакуйте содержимое `planetki-chibi.zip` в `E:/Planetki/Assets/composer/planetki-chibi`. Перезапустите игру. ZIP включает базовые восемь внешностей обоих полов и выбранных персонажей, весь каталог модулей и 123 анимации для child / teen / adult / elder.

Лица компилируются штатным вычислителем редактора: рот, брови, моргание, подгонка бороды и маски головных уборов. Возраст youth игры соответствует teen. Внешность сохраняется у CitizenNPC по visual_appearance_id и не меняется вместе с профессией. Карта, армейские фигурки, бой и портреты используют наш каталог.

Экспорт добавляет картинки, а не игровые предметы. Характеристики и рецепты остаются в `src/combat/equipment_db.gd`. Связь игровых ID с модулями — `src/core/composer_assets.gd`. Например short_sword → weapons_2, work_axe → weapons_4, hunting_bow → weapons_0. Иконки получают те же изображения через ItemTextureManager.

Мастерская расходует доставленные материалы и время производства, затем добавляет предмет в equipment_stockpile поселения. Вождь берёт его через существующий интерфейс снаряжения; при снятии предмет возвращается. Лук и копьё занимают обе руки: при выборе снимается щит, щит нельзя добавить к двуручному оружию. У лагеря лесорубов есть начальный набор каменных топоров, их прочность убывает; при нехватке лагерь забирает один произведённый топор со склада. Смена профессии лесоруба возвращает его инструмент на стойку с оставшейся прочностью.

## Деревья

Кнопка **Три дерева** добавляет дуб, сосну и берёзу в текущий проект. Раздел **Предпросмотр** показывает четыре клипа: покой, рубку, падение и брёвна. Обычные форматы экспорта кадров остаются доступны. Кнопка Godot экспортирует `planetki-trees.zip`: распаковать в `E:/Planetki/Assets/composer/trees`.

В игре нужны лагерь лесорубов, лесоруб и зона вырубки. Удары создают щепки и зарубку. Древесина остаётся у дерева: standing → falling → logs → stump. Подбор разрешён после 1,2 секунды падения. Остаток брёвен сохраняется на земле, если житель не может унести всё. Груз физически переносится в лагерь, а затем на склад. Сохранение содержит стадию, зарубку, таймер падения и оставшееся количество.

## FAQ

**Меч экспортирован, но его нет на складе.** Изображения не создают экономические запасы: предмет нужно произвести по рецепту.

**Почему человек сменил профессию, но не получил оружие?** Внешность и профессия независимы от инвентаря. Предмет появляется только при фактическом получении снаряжения.

**Почему после падения есть пень?** Это отработанный ресурсный узел. Брёвна рядом доступны для подбора; пень не добавляет древесину повторно.

**Почему в готовой сборке пак не находится?** В Godot в дополнительных файлах экспорта должны быть включены `Assets/composer/**/*.json`. Исходные PNG импортируются Godot стандартно.

**Можно импортировать произвольный новый рисунок вместо предмета?** Этот профиль поддерживает чиби-пак и три дерева. Новому предмету вне каталога нужны игровой ID, рецепт и запись соответствия. Произвольные рисунки можно экспортировать обычными PNG/SVG форматами.
