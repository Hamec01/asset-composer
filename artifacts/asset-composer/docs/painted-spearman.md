# Рисованный копейщик

В библиотеке персонажей кнопка **Копейщик · Рисованный чиби** создаёт отдельного
персонажа с новым сегментированным рисунком, комплектом одежды и копьём.
Повторное нажатие выбирает существующего копейщика, сохраняя ручные изменения.
Исходные PNG и описание происхождения находятся в `src/assets/spearman`.
Атлас используется через обрезаемые composite-области; ресурсы включаются в
переносимый проект один раз. Голова, шея, конечности, лицо, волосы и борода
редактируются и привязываются отдельно.

Два пользовательских клипа: **Копьё · Боевая стойка** и **Копьё · Укол с выпадом**.
Укол длится 1200 мс, контрольные фазы: 0 / 240 / 420 / 540 / 700 / 1200 мс.
Обе кисти следуют одной жёсткой системе координат древка, расстояние хвата —
46 единиц рига. Левая кисть держит древко у пояса, правая направляет его вперёд.
Локти расходятся от собственных плеч; при ударе передняя рука вытягивается.
Рисунок остаётся чиби, это постановочная 2D-анимация без физической симуляции.

`tests/paintedSpearman.test.ts` проверяет переносимое сохранение, длины рук,
контакт кистей с древком, широкий хват и положение локтей во всех кадрах и
обоих направлениях. Это дополняет обязательную визуальную проверку общего
Animation Review, не заменяя её.

Для генерации проекта, RIGHT/LEFT review SVG/PNG/JSON/ZIP и spritesheet:

```powershell
$env:SPEARMAN_OUTPUT='E:/vectoreditor/output/spearman-v3'
pnpm --filter @workspace/asset-composer test:run tests/paintedSpearman.test.ts --maxWorkers=1
```

`SPEARMAN_BASE_PROJECT` позволяет добавить/обновить комплект в копии заданного
проекта, сохраняя остальные объекты и идентификатор копейщика.
`SPEARMAN_PREVIEW_ONLY=1` создаёт только проект и две художественные позы.
Обычный запуск тестов не пишет артефакты.
