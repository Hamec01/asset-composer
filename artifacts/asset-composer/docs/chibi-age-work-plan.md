# Возраст и профессии: реализация

Источник: список ролей пользователя от 09.10.2026. Документ описывает требования к ассетам; игровое управление WASD, экономика, AI работников и боевой урон в редактор не добавляются.

1. Четыре возраста в существующем формате персонажа; взрослый по умолчанию для старых проектов. Реальные матрицы костей сохраняют привязки лица, одежды и реквизита. Детям и подросткам не предлагаются бороды.
2. Каталог всех действий из списка: 89 добавленных клипов, всего 123. Физически одинаковые действия используют общую основу движения; имена для игровых ролей сохранены. Безрукая форма токена передаёт работу движением корпуса, головы и отдельного инструмента.
3. Независимые растровые детали: 16 одежд, 56 инструментов и предметов; 25 вариантов крепления второго инструмента. Станки и декорации имеют отдельное крепление. Выбор клипа никогда не выбирает вещи.
4. Группы действий, стрелки выбора клипа, возраст, рекомендации реквизита и команда снятия экипировки. Инструкция и FAQ описывают точные названия кнопок.
5. PNG-листы на чистой основе, JSON клипов, отдельные PNG/SVG-модули, возрастные варианты базовых действий, пример редактируемого проекта и ZIP.
6. Приёмка: все возраста × все клипы без экипировки; сохранение/валидация проекта и обновление старого рига; общий прогон 2 workers / 30 секунд, typecheck, build. Для боевых действий — оба направления общего Animation Review, Rig → Depth → Skeleton → Normal → Accept.

Сценарии выполнены: создание ребёнка и подростка; случайная внешность без вещей; ручная примерка новой туники и молотка; снятие экипировки с сохранением лица; фильтрация по профессиям; возрастные листы и примеры ремёсел. Общий прогон: 394 теста прошли, 144 опциональные проверки генерации пропущены. Генерация экспортных артефактов запускается отдельно через CHIBI_PACK_OUTPUT.
