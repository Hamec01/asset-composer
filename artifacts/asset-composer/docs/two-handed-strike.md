# Удар двуручным мечом

Клип `chibi_front__two_handed_sword_strike`: 1600 мс, 30 fps, без зацикливания.
Это анимация хвата и тела без обязательного экипированного меча.

Обе ладони следуют двум сокетам одной виртуальной рукояти. Расстояние между
сокетами — 15 единиц. Сегменты рук сохраняют длину 15/13; недостижимую цель
нельзя исправлять растяжением. Расчёт отражается влево после решения IK.

Фазы: стойка → боковой замах → крайняя точка (600 мс) → разгон → контакт
(880 мс) → движение после удара → возврат в исходную стойку (1600 мс).
Виртуальная рукоять поддерживает easing исходящего отрезка:
`linear` (по умолчанию), `smooth`, `ease_in`, `ease_out`.
Интерполируется общий предмет, а не каждая кисть отдельно.

Замах замедляется, удар ускоряется, возврат тормозит перед стойкой.
Рукоять обходит голову сбоку и снизу: короткие руки чиби не вытягиваются
искусственно над макушкой. Поворот корпуса сопровождает движение.

Загрузчик обновляет только точно совпадающие прежние встроенные версии;
изменённые пользователем ключи, IK, drawOrder и исключения не заменяет.

## Окклюзия и зазор головы

Обычная ближняя кисть — NEAR_LIMB, а не HAND_FRONT. В этом клипе дальнее
плечо — FAR_LIMB, дальние предплечье/кисть — CROSS_BODY, вся ближняя рука —
NEAR_LIMB. Голова остаётся выше рук. Семантические слои применяются после drawOrder.

`headClearance.ts` берёт worldBounds настоящего визуала головы из evaluateScene.
Запретная область — внутренний эллипс 76%. Проверяются центр изображения ладони,
IK gripSocket (без него — запястье) и весь отрезок локоть–запястье. Проверка не
растягивает и не переставляет руки автоматически: автор исправляет траекторию.
Исключения `headOverlap` задают startMs включительно, endMs исключительно,
конкретные bones и непустой reason; HAND_FRONT сам по себе исключением не является.
Для меча исключений нет. Debug → Skeleton показывает эллипс и предупреждения;
экспорт диагностики включает нарушения по кадрам. Валидатор глубины предупреждает
о необоснованном HAND_FRONT, двух кистях впереди и длительных overrides.

Проверки: обе ладони на рукояти, постоянные длины рук, стойка ног,
зеркалирование, возврат, темп по фазам, отсутствие скачков >10 единиц
и поворотов >45° за полукадр, сериализация и сохранение пользовательских правок.
Зазор головы проверяется в 121 момент для каждого направления; отдельно проверяется
реальный порядок визуалов после evaluateScene, а не только состояние клипа.
Контрольные картинки: тест `twoHandedSword.test.ts` при заданной переменной
`SWORD_REVIEW` (путь без расширения) использует общий Animation X-Ray:
`-right.svg`, `-left.svg`, `-review.json`, без оружия. На листах колонки
NORMAL / RIG COLORS / DEPTH COLORS / SKELETON, шесть именованных фаз от Guard
до Recover. Обычный прогон не создаёт картинки. Инструкция и обязательная
визуальная приёмка: [Animation X-Ray](animation-xray.md).
