# Дуб, сосна и берёза

Оригинальные PNG с прозрачностью созданы встроенным imagegen. Каждый атлас содержит целое дерево, вариант с зарубкой, пень, брёвна и отдельные щепки. `manifest.json` описывает точные области; соседние рисунки не включаются в брёвна.

В приложении нажмите «Три дерева». В «Предпросмотр» доступны покой с ветром, рубка со щепками, падение и брёвна. Экспорт Godot создаёт `planetki-trees.zip` для `Assets/composer/trees`.

Задание для генерации: рисованные средневековые игровые ассеты в стиле чиби-пака, тёплые цвета, тёмный контур, прозрачный фон, без травы и персонажей. Для каждой породы — одинаковые здоровое и надрубленное дерево в верхнем ряду, пень слева снизу, брёвна и отдельные летящие щепки справа снизу. Дуб с широкой кроной, сосна с ярусами хвои, берёза с белой корой.

Исходники генерации сохранены без перерисовки: oak.png, pine.png, birch.png. Координаты регистрирует scripts/register-trees.py.
